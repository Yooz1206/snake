# 真机核对清单 (v1.1)

自动化能覆盖到这里为止：`tools/v11-check.mjs` 验状态机与分享卡，`tools/device-check.mjs` 用设备仿真验布局、触控尺寸与 iOS 提示逻辑。**仿真不是真机**——Safari 的分享面板、微信 WebView 的降级、iOS 的安全区与主屏启动，只能在实体设备上确认。

每次发布前，按下面这张表走一遍，把结果记在 PR 里。

## 准备

```bash
python -m http.server 8123         # 或直接开线上 Pages
```

调试 iOS 提示不必等七天，在 Safari 控制台里造状态再刷新：

```js
localStorage.setItem('snake:firstSeen:v1', String(Date.now() - 8 * 864e5));
localStorage.removeItem('snake:iosTipSeen:v1');
location.reload();
```

## iOS Safari（iPhone，iOS 15.4+）

- [ ] 首屏：标题「每日挑战」，副标题带「今日剩 3 次」，无横向滚动
- [ ] 点按棋盘任意位置即开始（不需要先点按钮）
- [ ] 滑动转向，不会被页面滚动抢走
- [ ] 切到后台再回来：出现 3-2-1，倒计时期间不移动、不死亡
- [ ] 刘海/灵动岛机型：HUD 与页脚不被安全区裁掉（竖屏 + 横屏各看一次）
- [ ] 分享：弹出系统面板并带图（iOS 15.4+ 支持文件分享）
- [ ] 分享面板点「取消」：无报错、按钮恢复可点
- [ ] 分享 → 添加到主屏幕 → 从主屏启动：全屏、无地址栏、可玩
- [ ] 从主屏启动后**不再**出现安装提示（standalone 判定）
- [ ] 飞行模式刷新：仍能打开并完成一局
- [ ] 开启「减弱动态效果」：无粒子、无震屏、倒计时只有数字切换
- [ ] VoiceOver：能听到开始、破纪录、结束、剩余次数

## Android Chrome（100+）

- [ ] 首屏布局与触控同上
- [ ] 浏览器菜单出现「安装应用」/ 地址栏安装图标
- [ ] 安装后从桌面启动：standalone、离线可玩
- [ ] 分享：系统面板带图；取消无报错
- [ ] 断网重载可玩

## 微信 / 飞书 / QQ 内置浏览器

- [ ] 页面能正常加载（不白屏）
- [ ] 分享按钮：`navigator.share({files})` 不支持时不报错
- [ ] 降级到下载 PNG；下载被拦时降级到复制文案，并出现「已复制文案」提示
- [ ] 文案里没有种子、路径、食物位置

## 桌面

- [ ] Chrome / Edge / Firefox / Safari：方向键与 WASD 都能转向
- [ ] 按钮获得焦点时按空格：只触发一次（不会开始又暂停）
- [ ] 练习模式：`R` 第一次暂停并提示「再按 R 重开」，2 秒内第二次才重开
- [ ] 每日模式：`R` 只暂停，提示「R 无效」
- [ ] 运行中切标签再回来：倒计时；对局进行中来了新版本，不自动刷新

## 记录方式

```
设备 / 系统 / 浏览器版本：
结果：通过 / 失败（附截图）
失败项：
```

失败的项如果真的只在真机出现（例如 Safari 分享面板的行为），把它补成一条 PRD 的已知限制，而不是在代码里猜。
