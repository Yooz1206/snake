# Snake v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.1 of the Snake game — daily challenge, shareable result card, real offline/PWA, and the promise-level fixes — on top of the v1.0 baseline (commit `2aaa995`).

**Architecture:** Stay a zero-dependency static site with native ES modules and no build step. `game.js` keeps every rule and all state transitions and stays DOM-free; new pure modules (`rng.js`, `daily.js`, `share.js`, `pwa.js`) hold the testable logic; `main.js` wires them to the DOM. Seeded randomness is injected into `SnakeGame`, so the same date plus the same input sequence produces the same run.

**Tech Stack:** Vanilla ES modules, Canvas 2D, `localStorage`, Service Worker, Web Share API. Tests: `node --test` (no dependencies). Browser smoke test: `tools/cdp-check.mjs` over the DevTools Protocol.

**Spec:** `docs/superpowers/specs/2026-10-20-snake-v1.1-prd.md` (PRD v1.2, including the §0.6 decisions: 3 daily attempts, share card shows the attempt number, north-star metric deferred to T14)

## Global Constraints

- Zero runtime dependencies; no build step; `node --test` green after every task (v1.0's 17 tests must keep passing — R4.10).
- `js/game.js` must not touch the DOM, read the clock, or call `Math.random` directly — the RNG is injected (10.1).
- Every tunable value lives in `js/config.js`; no magic numbers in modules (R7.7).
- localStorage keys and shapes are fixed: `snake:best` (number), `snake:muted` (`'0' | '1'`), `snake:seen:v1` (`'1'`), `snake:daily:v1:<YYYY-MM-DD>` (`{attemptsLeft, best, runs}`), `snake:streak:v1` (`{count, lastDate}`), `snake:iosTipSeen:v1` (`'1'`).
- Daily: 3 attempts, `attemptsLeft` clamped to 0–3, seed = `fnv1a32('snake:v1:' + date)`, RNG = `mulberry32(seed)` (7.1, 10.4).
- Streak only settles when `score >= 10`; `< 10` neither counts nor resets (R1.7).
- Share card is 1080×1350 PNG drawn locally, and `share.js` is loaded with a dynamic `import()` so it never enters the first paint (9.1).
- First paint ≤ 42KB uncompressed; `--muted` becomes `#7a8796`; every clickable target is ≥ 44×44 CSS px (R6.1, R6.2).
- UI copy comes verbatim from the §8.2 copy table; HUD `SCORE / BEST / DAILY / SNAKE` stay English (OQ6).
- No third-party requests, no cookies, no analytics (9.4).

## Review Focus

1. **Storage is unusable or corrupt** (`getItem` throws, quota exceeded, JSON is `"{"`): the game must run on in-memory defaults, never crash, and never overwrite `snake:best` with 0.
2. **Date boundary and clock rollback**: a run that started at 23:59 must settle against its `runDate`, not the new day; an illegal date falls back to today.
3. **Leaving during the 3-2-1 countdown**: switching tabs again resets the countdown, and more than three quick leaves ends the run with reason `leave` instead of granting invulnerability.
4. **Board fills up**: status becomes `won`, the simulation stops, and no code path tries to read `food.x` from `null`.
5. **Share path fails** (no `navigator.share`, `toBlob` returns null, user cancels): fall through to download, then to a text copy; cancellation is silent.

```js
test('fnv1a32 is a stable 32-bit hash', () => {
  assert.equal(fnv1a32(''), 0x811c9dc5);

  const a = mulberry32(seedForDate('2026-10-20'));
  const b = mulberry32(seedForDate('2026-10-21'));
  assert.notDeepEqual([a(), a(), a()], [b(), b(), b()]);
});
```

- Produces on `SnakeGame`:

  - `startDaily(runDate: string) -> void` sets `this.runDate`
  - `quit() -> void` → `status 'over'`, event `{ type: 'die', reason: 'quit' }`

  - `beginCountdown()` (`paused` → `countdown`), `endCountdown()` (`countdown` → `running`)

```js
test('the same seed and the same inputs produce the same run', () => {
  const play = () => {
    const game = new SnakeGame(CONFIG, mulberry32(seedForDate('2026-10-20')));
    game.start();
    const trace = [];
    for (let i = 0; i < 60; i += 1) {
      if (i % 7 === 0) game.queueDirection('up');
      if (i % 11 === 0) game.queueDirection('right');
      game.step();
      trace.push(JSON.stringify([game.snake, game.food, game.score, game.interval]));
    }
    return trace;
  };
  assert.deepEqual(play(), play());

test('filling the board wins instead of starving', () => {
  const game = new SnakeGame({ ...CONFIG, cols: 3, rows: 3, startLength: 1 }, () => 0);
  game.status = 'running';
  game.snake = [{ x: 1, y: 1 }];
  game.food = { x: 2, y: 1 };

  assert.equal(game.status, 'won');
  assert.equal(game.drainEvents().at(-1).type, 'win');

test('countdown ignores steps and cannot kill', () => {

test('daily mode never restarts from the keyboard', () => {
```
